## Purpose

With Phase 4 complete—providing a robust evidence layer through case studies—we now proceed to Phase 5: Polish and Production. This phase prepares the MICOS-25 book for publication. The key outputs are:

2. **Fact-Check and Validate:** Ensuring all concepts are accurate.
3. **Style Guide Application:** Consistent formatting throughout.
4. **Table of Contents:** A comprehensive, linked TOC.

## Step 5.3: Apply the Style Guide

### Purpose

Run the entire document through a style check for formatting, capitalization, and punctuation consistency. Ensure the book adheres to the style guide established in Phase 0.

### Style Guide Checklist

| Element | Standard | Check |
|---|---|---|
| **Headings** | `# H1`, `## H2`, `### H3`, `#### H4`, `##### H5` | ☐ |
| **Bold** | `**Text**` for emphasis and key terms | ☐ |
| **Italics** | `*Text*` for technical terms on first use and case names | ☐ |
| **Code Blocks** | ` ``` ` for matrices, tables, and code | ☐ |
| **Blockquotes** | `> ` for extracted quotes or key insights | ☐ |
| **Lists** | `- ` for unordered lists, `1. ` for ordered lists | ☐ |
| **Links** | `[Text](URL)` for cross-references and external links | ☐ |
| **Tables** | Markdown tables with `|` separators | ☐ |
| **Chapter Titles** | Title Case (e.g., "Chapter 3: Capital Structure") | ☐ |
| **Section Headings** | Title Case (e.g., "Strategic Function") | ☐ |
| **Subsection Headings** | Sentence case (e.g., "What is it?") | ☐ |
| **Key Terms** | Bold on first use, then standard | ☐ |
| **Chapter References** | "Chapter X: [Name]" | ☐ |
| **Framework References** | "MICOS-25" always with hyphen and numbers | ☐ |
| **Layer References** | "Layer 1: Structural Foundation" | ☐ |
| **Example Introductions** | `**Example:**` in bold, followed by italicized company name | ☐ |
| **Company Names** | Italicized, descriptive names (e.g., *GreenTech Innovations*) | ☐ |
| **Case Study Names** | Italicized, descriptive names (e.g., *The "Silent" MFN*) | ☐ |
| **Cross-References** | `Chapter X: [Name]` (e.g., "See Chapter 2: Governance") | ☐ |
| **Section References** | `Section X.Y: [Name]` | ☐ |
| **Voice** | Active voice preferred over passive | ☐ |
| **Tense** | Present tense for definitions and principles; past tense for examples | ☐ |
| **Pronouns** | Use "you" sparingly; prefer "the institution," "the board," or "the architect" | ☐ |

## Step 5.7: Generate the E-Book Format

### Purpose

Create a polished PDF and an EPUB version of the book for broad distribution. The PDF should be print-ready; the EPUB should be optimized for e-readers.

### PDF Requirements

| Requirement | Description |
|---|---|
| **Page Size** | Standard 6" x 9" (trade paperback) or 8.5" x 11" (letter) |
| **Margins** | 1" margins on all sides |
| **Font** | Serif font for body (e.g., Times New Roman), sans-serif for headings |
| **Font Size** | 11pt for body, 14-18pt for headings |
| **Page Numbers** | Bottom center or bottom right |
| **Headers/Footers** | Chapter title on verso, book title on recto |
| **Links** | Working hyperlinks for cross-references, TOC, and index |
| **Bookmarks** | PDF bookmarks for all chapters and sections |
| **Cover** | Custom cover design |

### EPUB Requirements

| Requirement | Description |
|---|---|
| **Format** | EPUB 3 standard |
| **Reflowable** | Reflowable text for variable screen sizes |
| **Embedded Fonts** | Standard fonts for readability |
| **Working Links** | All cross-references and TOC links working |
| **Metadata** | Title, author, description, keywords |
| **Cover** | Cover image embedded |
| **Table of Contents** | NCX navigation |
| **Accessibility** | Basic accessibility features (alt text for images, semantic markup) |

### Conversion Tools

| Tool | Purpose |
|---|---|
| **Pandoc** | Conversion from Markdown to PDF and EPUB |
| **Calibre** | E-book conversion and management |
| **Adobe Acrobat** | PDF generation and optimization |
| **Sigil** | EPUB editing |

### E-Book Generation Steps

| Step | Action |
|---|---|
| **1** | Export the book from Markdown to DOCX or HTML. |
| **2** | Use Pandoc to generate the initial PDF. |
| **3** | Use Pandoc to generate the initial EPUB. |
| **4** | Review the PDF for formatting issues. |
| **5** | Review the EPUB on multiple devices (phone, tablet, e-reader). |
| **6** | Make necessary corrections. |
| **7** | Regenerate both formats. |
| **8** | Final review. |
